Sun Runner

MODE ADMIN

ÉDITION DÔME

Fuis vers l'horizon avant que le soleil ne s'éteigne. Évite les blocs, récupère les cristaux et complète les défis pour débloquer des améliorations.

Difficulté

Commandes
Tactile : glisse le doigt pour diriger le vaisseau.
Clavier : flèches ou WASD / ZQSD.
Turbo : Maj ou Espace (bouton TURBO sur mobile). Il se recharge avec les cristaux et les frôlements.
Pilote auto : touche O ou bouton PILOTE AUTO.
Fantôme : touche G ou bouton FANTÔME (traverse les obstacles 4 s, recharge 14 s).
Les cristaux verts donnent un bouclier.

ACCÈS ADMIN

Entre ton code secret pour débloquer les options de triche.
